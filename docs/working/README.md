# Working on a project

How to organise the work of reverse engineering a game, for agents and the people who direct
them. The skills describe each step of the method. These pages describe the habits that make
the steps add up.

- [Working well as an agent](agents.md): the repository as memory, how to start a session,
  measuring before porting, working in subsystems, splitting work between sessions, what to
  do when stuck, and how to report.
- [Writing findings and documents](writing.md): plain English, the patterns to avoid, evidence
  labels, the structure of a findings document, commit messages.
