# Sources and notes

The report and the four sets of notes below give the sources for the
[preservation chapters](../README.md). Every finding links to its source. The notes keep cited
findings apart from inferences, and each lists its gaps. A finding marked "(search snippet)"
comes from a search result, because the page itself could not be fetched.

1. [Report: presenting the harness as game preservation](report.md): the summary of the notes, with
   draft wording for the site.
2. [Notes: why games disappear](why-games-vanish.md): the 2023 availability study, games that
   stop running, games still on sale but frozen, lost source code and media.
3. [Notes: law and policy](law-and-policy.md): the US, the EU and the UK, "abandonware",
   takedowns, rights holders who released code.
4. [Notes: who preserves games](ecosystem.md): institutions, emulation, community
   reimplementations, decompilation.
5. [Notes: how preservation projects describe their work](messaging.md): mission statements,
   words to use and avoid, critiques, the concern about AI.

## Facts checked against primary sources

| Claim | Result |
|---|---|
| UK CDPA s.50B and s.50BA | Confirmed on [legislation.gov.uk](https://www.legislation.gov.uk/ukpga/1988/48/section/50B): decompilation for an independent program that works with the original, and observing, studying and testing while running it |
| Software Directive Art. 6(2)(c) | Confirmed: the information may not be used for a program "substantially similar in its expression" ([legislation.gov.uk copy](https://www.legislation.gov.uk/eudr/2009/24/article/6)) |
| Rosetta 2 | General use through macOS 27; from macOS 28 only a part, for older games ([MacRumors](https://www.macrumors.com/2026/02/16/macos-tahoe-26-4-rosetta-2-warnings/)) |
| OpenTTD and Atari, March 2026 | Confirmed on [openttd.org](https://www.openttd.org/news/2026/03/19/steam-changes-update) |
| decomp.dev closure | Confirmed in [404 Media](https://www.404media.co/video-game-reverse-engineering-community-shuts-down-because-ai-has-made-it-too-easy/), 15 October 2026 |
| GOG Preservation Program launch | Not settled. GOG's press release is reported as 13 October 2024, and some coverage gives 13 November 2024. The chapters say "late 2024" |
| Windows 11 is 64-bit only | Windows 11 has no 32-bit edition; the chapters rely on this |

## Gaps

- No count exists of games still on sale that their makers no longer update.
- The notes do not cover the Library of Congress, MoMA or the Internet Archive's software
  collections in depth.
- What preservation groups asked for in the 2027 US rulemaking (docket COLC-2026-0100) was not
  found.
- No developer or publisher statement about this harness, or about Un-Banished, was found.
