# Game preservation

Many older games can no longer be bought. Many games people own no longer run on current
computers. Some games are still on sale, but nobody has updated them in years. This harness
helps the owner of such a game keep it playable. It works from the copy the owner bought. It
rebuilds the game in new code that behaves exactly like the original, and it writes down how
the game works along the way.

The harness does not share games. It ships no game files, assets or decompiled code. It is
tested only on sample programs written for it.

These chapters explain why games need this care, what the harness does about it, and where
its limits are.

1. [Why games disappear](why-games-disappear.md): out of print, broken by new systems, frozen
   by their makers, lost at the source.
2. [What the harness does](what-the-harness-does.md): a record of how the game worked,
   checked against the original, and what the harness cannot do.
3. [Your own copy and the law](the-law.md): the rules in the US, the EU and the UK, the myth
   of "abandonware", and what takedowns have shown.
4. [AI and reverse engineering](ai.md): the concern about AI copying games, and how the
   harness answers it.
5. [Built on others' work](others-work.md): the projects and institutions this harness learns
   from, and where to read more.
6. [For developers and publishers](rights-holders.md): what we promise the people who made
   these games, and how to reach us.
7. [Sources and notes](research/README.md): the report and notes behind every claim here, the
