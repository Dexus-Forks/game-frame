# In your browser

Tools that run in this page, on a file you choose. The file is read by your browser and stays on your computer. Nothing is uploaded. Each tool is the browser version of a GameFrame tool,
with the same rules, so a result here matches the one the tool gives in a project.

- [File explorer](/lab/files): what a file is, a map of its bytes, its entropy along its length,
  and the bytes at any place you click. The same as `tools/triage/filetypes.py` and
  `tools/triage/binview.py`.
- [Pixel explorer](/lab/pixels): try bytes as a picture, and change the mode, the width, the
  offset and the palette until it stands straight. The same as `tools/formats/rawimage.py`.

- [Records explorer](/lab/records): a table of records or a capture of network messages, one
  row each, with the counters, lengths and types marked. The same as `tools/formats/fields.py`
  and `tools/formats/pcap.py`.

Files from a game are the game's own material. Use your own copy, and keep what you make from
it in your project's ignored folders.
